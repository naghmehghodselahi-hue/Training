# Lesson Notes

اکستنشن کروم برای ساختن ترانسکرپت و جزوه‌ی آموزشی از هر ویدیویی که در یک تب پخش می‌شه، مخصوصاً ویدیوهای فارسی و ویدیوهای view-only گوگل درایف.

## چطور کار می‌کنه

۱. صدای تب رو موقع پخش ضبط می‌کنه. برای همین با ویدیوهایی که دانلودشون بسته‌ست هم کار می‌کنه.
۲. صدا رو تکه‌های ۳ دقیقه‌ای می‌کنه و برای تبدیل به متن به OpenAI می‌فرسته. ترانسکرپت همزمان با پخش ساخته می‌شه.
۳. ترانسکرپت رو به Claude می‌ده و یک جزوه‌ی آموزشی می‌گیره: خلاصه، اهداف یادگیری، مفاهیم کلیدی، چارچوب‌ها، مثال‌ها با زمان، نکات کاربردی، سؤالات مرور، و بخش‌هایی که نامفهوم بودن.
۴. می‌تونی درباره‌ی ویدیو سؤال بپرسی.

## نصب (حدود ۵ دقیقه)

۱. این پوشه (`lesson-notes-extension`) رو دانلود کن. از گیت‌هاب: Code ← Download ZIP، بعد از حالت فشرده درش بیار.
۲. در کروم برو به `chrome://extensions`.
۳. بالا سمت راست **Developer mode** رو روشن کن.
۴. **Load unpacked** رو بزن و پوشه‌ی `lesson-notes-extension` رو انتخاب کن.
۵. آیکون پازل کنار نوار آدرس رو بزن و Lesson Notes رو pin کن.

## کلیدهای API

- **OpenAI** (تبدیل گفتار به متن): از platform.openai.com ← API keys. باید کمی اعتبار شارژ کنی.
- **Anthropic** (جزوه و پرسش و پاسخ): از console.anthropic.com ← API keys. اینجا هم اعتبار لازمه.

اشتراک ChatGPT Plus یا Claude Pro برای API حساب نمی‌شه. API جدا شارژ می‌شه.

## استفاده

۱. ویدیو رو در درایف باز کن.
۲. روی آیکون Lesson Notes **در همون تب** کلیک کن تا پنل باز بشه. این کلیک لازمه، چون کروم فقط بعد از اون اجازه‌ی ضبط صدای تب رو می‌ده.
۳. زبان ویدیو و سرعت پخش رو انتخاب کن (همون سرعت رو در پلیر هم بذار). اصطلاحات تخصصی ویدیو رو اگه می‌دونی بنویس.
۴. **Start recording** و بعد play.
۵. آخر ویدیو **Stop**. چند ثانیه صبر کن تا تکه‌ی آخر هم متن بشه.
۶. اگه لازمه ترانسکرپت رو اصلاح کن، هدفت رو بنویس و **Create notes** رو بزن.

## محدودیت‌ها، صادقانه

- ویدیو باید پخش بشه. یک ویدیوی یک‌ساعته با سرعت ۲x حدود ۳۰ دقیقه طول می‌کشه.
- پنل باید تا آخر ضبط باز بمونه.
- اگه وسط ضبط سرعت پخش رو عوض کنی یا ویدیو رو جلو و عقب کنی، زمان‌های ترانسکرپت جابه‌جا می‌شن.
- کیفیت تشخیص گفتار فارسی خوبه ولی بی‌نقص نیست، مخصوصاً با صدای ضعیف، لهجه یا اصطلاحات انگلیسی وسط حرف. جزوه بخش‌های نامفهوم رو جدا علامت می‌زنه.
- با gpt-4o-transcribe زمان‌ها در حد هر ۳ دقیقه‌ست. برای زمان‌های دقیق‌تر whisper-1 رو انتخاب کن (کیفیت فارسی‌ش ممکنه کمتر باشه).

## هزینه

برای استفاده‌ی شخصی کمه، ولی قیمت‌ها عوض می‌شن، پس از صفحه‌ی قیمت‌های OpenAI و Anthropic چک کن. تقریباً بیشترش هزینه‌ی تبدیل گفتار به متنه که به ازای دقیقه‌ی صدا حساب می‌شه.

## حریم خصوصی

صدا به OpenAI و متن به Anthropic فرستاده می‌شه. کلیدها فقط در همین مرورگر ذخیره می‌شن. برای محتوای محرمانه‌ی سازمانی، اول از سیاست سازمان یا صاحب محتوا مطمئن شو.
